# 特定技能2号（建設分野・鉄筋）受験対策キット

特定技能1号で働く鉄筋工を2号へ進めるための受験対策セットです。
「建設分野特定技能2号評価試験」の**建築区分**を想定し、鉄筋の班長が押さえるべきことだけに絞っています（情報は2026年9月時点）。

## このキットの中身

| ファイル | 内容 | 使い方 |
|---|---|---|
| [index.html](index.html) | 学習アプリ（要点まとめ10章・学科模試40問・実技模試25問・用語集59語） | ダウンロードしてスマホ・PCのブラウザで開く。自動採点、タイマー、まちがえた問題の復習、ふりがな切替（上／かっこ／なし） |
| [mogi_gakka.md](mogi_gakka.md) | 学科模試の問題冊子＋解答・解説 | 印刷して紙で解く。ふりがなは本番と同じ「漢字（かな）」形式 |
| [mogi_jitsugi.md](mogi_jitsugi.md) | 実技模試（建築区分・鉄筋重点）の問題冊子＋解答・解説 | 同上。図は `img/` フォルダ |

- 模試の問題は、JACの公式テキスト・サンプル問題の出題範囲に合わせて作ったオリジナル問題です（公式問題ではありません）。
- アプリと問題冊子は同じ問題・同じ選択肢の順番です（アプリで「選択肢の順番を入れ替える」をオンにした場合を除く）。

### index.html の開き方

1. このページの `index.html` を開き、右上の **Download raw file** で保存
2. 保存したファイルをスマホ・PCのブラウザで開く（インターネット接続がなくても動きます）
3. 成績と「まちがえた問題」は、その端末のブラウザに保存されます

## まず確認：2号になるための2つの条件

| 条件 | 内容 | 注意点 |
|---|---|---|
| ① 試験に合格 | 建設分野特定技能2号評価試験（従事する業務区分で受験）、または技能検定1級 | 日本語試験は不要 |
| ② 班長の実務経験 | CCUS能力評価基準のレベル3相当の「就業日数（職長＋班長）」。**鉄筋は3年（645日）以上** | 原則CCUSの就業履歴で確認。記録が足りない期間は、申告書（分野参考様式第6-3号）と就業証明書で確認 |

> **鉄筋の班長経験の要件は、職種ごとの区分（0.5年／1年／2年／3年）のうち最も長い3年（645日）です。** 試験に合格しても、日数が足りなければ2号へ変更できません。職長・班長として働いた日をCCUSのカードタッチで確実に記録してください。
> 求められるのは「レベル3の取得」ではなく「レベル3相当の就業日数（職長＋班長）」です。

### 受験区分の選び方（鉄筋施工は「建築」「土木」の両方に含まれます）

| 普段の仕事 | 受ける区分 | このキット |
|---|---|---|
| 建物（マンション・ビル・工場など）の鉄筋 | 建築 | 学科・実技ともそのまま使える |
| 橋・擁壁・トンネルなど土木構造物の鉄筋 | 土木 | 学科は使える。実技はJACの土木区分テキストを追加で学習 |

## 試験の概要

| 項目 | 学科 | 実技 |
|---|---|---|
| 問題数・時間 | 40問・60分 | 25問・40分 |
| 出題内容 | 全区分共通。班長の職務、現場管理（工程・品質・原価）、安全衛生、設計図書・施工図、建設業のしくみ・法令 | 業務区分別（建築／土木／ライフライン・設備）。道具・材料・作業の知識。写真・イラストの問題あり |
| 形式 | CBT（パソコン）・4択 | CBT（パソコン）・4択 |
| 合格基準 | 75%以上 | 75%以上 |

| 項目 | 内容 |
|---|---|
| 合否 | 学科・実技の**両方**が75%以上で合格 |
| 水準 | 技能検定1級相当 |
| 実施・申込 | 実施はJAC（建設技能人材機構）。国内はプロメトリックのテストセンターで受験。予約は試験日の59日前から |
| 受験料 | 1,000円（2025年4月以降） |
| ふりがな | 2025年4月から、漢字の後ろに「設計図（せっけいず）」の形でふりがなが付く |
| 出題範囲 | JAC公式テキストのうち、1号テキストの学科（第1〜4章）・実技（第5〜7章）の範囲と、2号テキスト（班長の職務・現場管理・安全衛生・設計図書と施工図・建設業の理解の全5章） |
| 合格率の例 | 2026年2月（国内実施）：2号建築 63%（1,169人／1,844人）、2号土木 59%（629人／1,059人） |

## おすすめの進め方（8週間の例）

| 期間 | やること | 目標 |
|---|---|---|
| 1〜2週目 | アプリの「要点（学科）」を読み、学科模試を**練習モード**で解く | 解説を読んで理由まで言える |
| 3〜4週目 | 「要点（実技）」とJACの実技テキスト（建築）を読み、実技模試を練習モードで解く | 鉄筋の数値（かぶり・継手・圧接）を暗記 |
| 5〜6週目 | **本番モード**（時間あり）で解き、「まちがえた問題だけ練習」をくり返す | 学科・実技とも8割以上 |
| 7〜8週目 | JAC公式サンプル問題で仕上げ、受験予約 | 本番モードで安定して8割以上 |

## 会社のチェックリスト

- [ ] 本人のCCUS技能者登録と、職長・班長としての就業履歴（鉄筋は645日以上）を確認した
- [ ] 記録が足りない期間の証明方法（分野参考様式第6-3号の申告書・就業証明書）を確認した
- [ ] 受験区分（建築／土木）を決めた
- [ ] JAC公式テキスト・サンプル問題をダウンロードした
- [ ] 本キットの模試で、学科・実技とも安定して8割以上になった
- [ ] プロメトリックで受験を予約した
- [ ] 合格後、在留資格変更許可申請（1号→2号）の必要書類を、入管庁・国交省の最新の案内または登録支援機関・行政書士に確認した

## 2号になると変わること

| 項目 | 1号 | 2号 |
|---|---|---|
| 在留期間 | 通算5年まで | 更新の上限なし |
| 家族の帯同 | 原則できない | 配偶者・子の帯同が可能 |
| 支援計画 | 必要 | 不要 |

## 注意事項

- 模試の数値は、建築基準法施行令・労働安全衛生規則・JASS 5（日本建築学会）などの一般的な基準です。実際の工事では、図面・特記仕様書が優先です。
- 制度・試験の情報は2026年9月時点です。受験前に、下の公式情報で最新の内容を確認してください。
- 問題を直したいときは、`index.html` の中の `window.QDATA`（問題）・`window.NOTES`（要点）・`window.GLOSSARY`（用語）を編集します。問題冊子（.md）は別ファイルなので、同じ箇所を合わせて直してください。

# カットリスト作成（鉄筋の材質・径・長さごとの本数入力）

> 株式会社山村組の社内向けに作成した資料です。Kakeru の n8n テンプレートとは別のものです。

工場でほしい鉄筋の材料を、スマホで入力して1枚の画像にするためのページです。

- 開く: <https://kakeru-tools.github.io/kakeru-templates/kari-cutlist/>
  （LINE で送る時は、末尾に `?openExternalBrowser=1` を付けると Safari や Chrome で開きます）
- 開くと合言葉の入力が出ます。一度入ると、その端末では次から「ログイン」を押すだけで入れます。
- 材質と径を選び、長さ（3.5〜12.0m）ごとの本数を入れると、重量と合計が出ます。
- 「画像にする」で表の画像を作り、写真に保存したり送ったりできます。
- 入力した内容は、そのスマホの中だけに残ります。どこにも送られません。
- 重量の計算: 1本の重さ＝1mあたりの重さ×長さ（上から3けた）／行の重量＝本数×1本の重さ（kg）。
